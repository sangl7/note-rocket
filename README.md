# Note Rocket

A note-reading game for young piano students. A note appears on the staff; name it by tapping the on-screen keys, or switch on **Real piano** and play it on your own piano while the game listens through the microphone.

- 17 levels across treble clef, bass clef and the grand staff, taught landmark-first (Middle C, Treble G, Bass F, then their neighbours).
- Progress is stored in the browser on each device.

`note-rocket.html` is the source. Run `node build.mjs` to regenerate `index.html`, the page that is served.
